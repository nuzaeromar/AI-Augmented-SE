# Streamlit Shopping Cart

A simple Streamlit-based shopping cart application with product listing, cart management, and checkout.

## Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the App

Start the Streamlit app with:
```bash
streamlit run src/main.py
```

## Example Usage

1. Browse the product list
2. Click "Add to Cart" to add items
3. View your cart and adjust quantities
4. Click "Checkout" to complete your order

## Testing

Run tests with:

pytest tests/
